# Forever Guides

Forever Guides is the in-game companion for forever-guides.com for World of Warcraft: trainers, talents, macros, maps, guides, exports and more in one add-on.

Current version: 0.1.1

## Installation

1. Download `ForeverGuides-0.1.1.zip` from the latest release on the Releases page of this repository.
2. Extract the zip. It holds five folders: `ForeverGuides`, `ForeverGuides_GildenManager`, `ForeverGuides_MapData`, `ForeverGuides_Professions` and `ForeverGuides_Recipes`.
3. Copy all five folders into the `Interface/AddOns` folder of your game installation and restart the game or reload the interface.

### WowUp

Open WowUp, choose "Install from URL" and paste the URL of this repository. WowUp installs the newest release and keeps it up to date.

### CurseForge

Forever Guides is also published on CurseForge: https://www.curseforge.com/wow/addons
