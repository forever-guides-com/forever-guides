# Forever Guides

Forever Guides is the in-game companion for forever-guides.com for World of Warcraft: trainers, talents, macros, maps, guides, exports and more in one add-on.

Current version: 1.1.0

## Install

Pick one way. All of them install the same twelve folders.

- **CurseForge:** search for Forever Guides in the CurseForge app and install it.
- **Wago:** search for Forever Guides in the Wago app and install it.
- **WowUp:** open WowUp, choose "Install from URL" and paste the URL of this repository. WowUp installs the newest release and keeps it up to date.
- **Manually:** download `ForeverGuides-1.1.0.zip` from the release with that version on the Releases page of this repository and extract it. The zip holds sixteen folders: `ForeverGuides`, `ForeverGuides_Chat`, `ForeverGuides_Comprehension`, `ForeverGuides_Fishing`, `ForeverGuides_Gathering`, `ForeverGuides_GildenManager`, `ForeverGuides_InstanceData`, `ForeverGuides_Itemsets`, `ForeverGuides_Lockpicking`, `ForeverGuides_MapData`, `ForeverGuides_Professions`, `ForeverGuides_Recipes`, `ForeverGuides_Reputation` and `ForeverGuides_Nav_EK`, `ForeverGuides_Nav_Kalimdor`, `ForeverGuides_Nav_Zephras`. Copy all sixteen into the `Interface\AddOns` folder of your Forever client, then restart the game or reload the interface.
