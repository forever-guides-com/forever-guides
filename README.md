# Forever Guides

Forever Guides is the in-game companion for forever-guides.com for World of Warcraft: trainers, talents, macros, maps, guides, exports and more in one add-on.

Current version: 0.1.6

## Install

Pick one way. All of them install the same five folders.

- **CurseForge:** search for Forever Guides in the CurseForge app and install it.
- **Wago:** search for Forever Guides in the Wago app and install it.
- **WowUp:** open WowUp, choose "Install from URL" and paste the URL of this repository. WowUp installs the newest release and keeps it up to date.
- **Manually:** download `ForeverGuides-0.1.6.zip` from the latest release on the Releases page of this repository and extract it. The zip holds five folders: `ForeverGuides`, `ForeverGuides_GildenManager`, `ForeverGuides_MapData`, `ForeverGuides_Professions` and `ForeverGuides_Recipes`. Copy all five into the `Interface\AddOns` folder of your Forever client, then restart the game or reload the interface.
